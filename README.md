# agentic-adhoc
Ad-hoc repo for intent routing, tool use etc.

## Tracks
- [`design-agent-v0/`](design-agent-v0/) — bounded Design Agent runtime for
  design voting and try-on posters, with Curify integration patch, trace/eval
  harnesses, deterministic rendering, visual verification, and a runnable
  men's-grooming demo.
- [`visual-intent-routing/`](visual-intent-routing/) — Generative Retrieval for Template
  Recommendation (Rong). Layer-1 routing eval: capability KB, routing gold + ontology-enriched
  gold, Path A/B/union scorers. Self-contained (frozen `curify-frontend` data snapshots), runs
  standalone. See its [README](visual-intent-routing/README.md).

Daily updates / scripts / data / images for progress reviews go under the relevant track.
