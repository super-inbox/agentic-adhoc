# GRAIN & GLOW｜素笺礼序 v1 精修

状态：Territory B 已选；本轮仅应用客户指定 delta，不改动 v0 文件。

## 1. 客户本轮决定

- A（日光酥层）仍显得太网红，不再推进。
- C（城市酥谱）显得太老，不再推进。
- 选定 B（素笺礼序 / QUIET GIFTING）继续精修。
- B 需要更多留白。
- 现有 Logo 不得修改。
- 礼盒需要显得更贵。

## 2. 保持不变

- 现有 Logo 的结构、比例、中文品牌名及标准字不动。
- B 的核心语法仍是：素纸、墨黑、灰青、低光金属、编辑式秩序与礼赠仪式。
- 不引入 A 的暖色光感、社媒式裁切或滤镜。
- 不引入 C 的编号主导、模块色块或更具年代感的视觉语汇。
- 淘宝和门店的原有延展逻辑继续有效，本轮不另起一套渠道系统。
- 继续禁用：社媒贴纸拼贴、伪书法、印章、仿古边框、节庆红金、高饱和装饰字。

## 3. 本轮只改两项

### Delta 01｜增加留白

- v1 视觉样机把礼盒控制在画面约 28–34%，保留约 65–70% 安静留白。
- 构图取消装饰性背景、桌面道具和大面积产品裁切。
- 画面重心仍偏下，维持 B 的编辑式安静感。
- 上述比例是本轮用于验证方向的工作值，尚未作为最终渠道模板锁定。

### Delta 02｜提升礼盒溢价

“更贵”不靠增加装饰，而由以下四层承担：

1. **比例与结构**：低而宽的书型硬盒、锐利盒角、明确的 3 mm 阴影缝与受控开盒角度。
2. **材质层级**：暖象牙色无涂布纸、深墨色内托、灰青拉带、低光黄铜细边。
3. **Logo 区域**：盒盖只预留一个干净的内凹铭牌区；最终必须调用现有 Logo 标准文件原样落位。
4. **工艺克制**：极细矩形盲压框、纸纤维与精准侧光；不使用满版烫金、传统纹样或放射装饰。

## 4. Logo 锁定规则

- 当前视觉样机中的铭牌区保持完全空白，避免模型生成或重绘品牌标志。
- 不改变 Logo 图形、中文标准字、字距、组合关系或比例。
- 不把 Logo 转成印章、线稿、压纹图腾或新符号。
- 精确落位仍需现有 Logo / 中文标准字的 AI、SVG 或可编辑 PDF 源文件，以及安全区、反白和单色规范。

## 5. 对既有渠道延展的有限影响

### 淘宝

- 保留“素纸底 + 单一礼盒 + 两级信息”的结构。
- 主图提高空白比例，但品牌、品类、内含物仍需在一屏内可识别。
- 优惠信息继续进入独立规格栏，不覆盖礼盒与 Logo 安全区。

### 门店

- 保留灰青墙面、素纸灯箱和深色展台。
- 礼盒改用低宽比例陈列，并增加单盒之间的间距，强化“展品”感。
- 金属仍只用于盒边、灯箱细框或关键节点，不扩大为金色空间主题。
