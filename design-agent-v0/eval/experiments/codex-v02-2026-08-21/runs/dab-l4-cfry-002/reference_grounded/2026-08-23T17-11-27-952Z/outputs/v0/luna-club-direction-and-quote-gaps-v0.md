## 报价仍缺的输入

| 类别 | 需客户或工厂确认 | 对报价/出图的影响 |
|---|---|---|
| 数量 | 首单数量、阶梯报价数量、是否含打样 | 影响单价、开机与包装成本 |
| 主体板材 | 亚克力板厚、材质等级/允许色偏 | 影响材料、边缘观感与插槽配合 |
| 底座板材 | 底座板厚、材质等级 | 影响稳定性、成本和槽深 |
| 底座尺寸 | 长、宽、外形；是否有工厂标准底座可选 | 影响材料用量、稳定性和成品总高 |
| 插槽结构 | 槽宽、槽深、槽长、配合公差 | 决定能否装配；当前不得猜测 |
| 装配方式 | 可拆插装、胶粘或其他工艺 | 影响结构、包装和人工 |
| 印刷要求 | 单面/双面观看需求、印刷面、色彩标准 | 影响工艺与报价 |
| 白墨策略 | 满铺承白、局部白墨或透光区域要求 | 影响层文件与印刷次数 |
| 边缘工艺 | 激光切割边、抛光/倒角要求 | 影响外观与工时 |
| 包装物流 | 单个袋/盒、保护膜、内衬、运输地区与交期 | 影响包装及交付报价 |
| 工厂文件规范 | 刀线颜色/线宽、白墨专色名、出血/安全边、文件格式及版本 | 决定最终生产文件组织方式 |
