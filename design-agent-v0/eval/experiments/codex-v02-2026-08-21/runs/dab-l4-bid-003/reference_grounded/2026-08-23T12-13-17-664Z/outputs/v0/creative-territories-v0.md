# 工业传感器品牌 Creative Territories / v0

状态：等待客户选择方向。本文件只完成方向发散，不构成 Logo 定稿、字标规范或应用设计。

业务基线：**Reliable sensing for harsh environments / 面向严苛环境的可靠感知**；主要受众为设备制造商与系统集成商。

## 共同前提

- **保留项**：旧 Logo 的核心外轮廓与主要识别手势；本轮只假设整理内部结构、线宽、比例与字标关系，不另造一个替代性 Logo。
- **主色项**：深蓝始终占主导。下列色值只是用于区分方向的暂定色感，不是品牌规范。
- **气质项**：技术可信，但通过圆角、留白、材料色和克制的暖色节点避免“冷冰冰”。
- **禁用项**：不使用霓虹、电光、故障扫描线、赛博渐变或未经提供的认证徽标。
- **应用项**：所有方向都以官网首屏和大型展板的远距离识别为门槛。
- **双语项**：中文与英文字标须在下一阶段分别验证；本轮不因缺少正式品牌名而虚构字标。

## Territory 1 — 校准可信 / Calibrated Confidence

**核心叙事**：像一台校准过的仪器——准确、稳定、没有多余动作。

**设计语法**：严格网格、统一线宽、清晰负空间、少量圆角；深蓝结构配暖白底，铜棕只作小于约 10% 的提示色。暂定色感：深蓝 `#0A2342`、暖白 `#F4F0E8`、铜棕 `#B97846`。

### H1 精度整理 / Precision Cleanup

保留旧 Logo 外轮廓，只校正不一致的曲率、转角、笔画和重心。技术感来自比例精确，而不是添加“科技特效”。

- 可验证假设：缩至 24–32 px 仍能识别；放大到展板不会暴露凌乱节点。
- 风险：整理过度会显得机械；用略柔和的端点和暖白背景调节。

### H2 校准刻度 / Calibration Notch

在旧轮廓内部引入一个克制的校准缺口或基准线，暗示传感器的测量与标定；外轮廓不动。

- 可验证假设：销售团队能把它解释为“可测、可校准、可信赖”，而不是装饰。
- 风险：刻度太多会像仪表盘；只允许一个主要基准动作。

### H3 受护核心 / Protected Core

把旧轮廓理解为工业外壳，内部以一个稳定的感知核心或采样窗口组织负空间。

- 可验证假设：能传达“严苛环境中的可靠感知”，且不误读为盾牌认证。
- 风险：可能过于安全/防务化；避免徽章边框、星章和认证式环带。

**适合**：销售材料、规格页、设备铭牌、大型展板；三组中技术权威感最强。

## Territory 2 — 稳态信号 / Resilient Signal

**核心叙事**：信号穿过振动、尘土、温差与噪声，仍保持连续。

**设计语法**：旧轮廓作为稳定边界，内部使用一条连续路径或两层材料带；不使用发光。暂定色感：深蓝 `#0B2744`、矿物蓝 `#496C78`、暖砂 `#D0A36A`。

### H4 连续信号 / Continuous Path

沿旧轮廓内部组织一条不间断的线，象征从感知、传输到系统集成的连续可靠性。

- 可验证假设：动态场景中可以自然演绎，静态 Logo 又不依赖动画成立。
- 风险：易落入“连接/云服务”俗套；不使用网络节点阵列或无限循环符号。

### H5 环境分层 / Environmental Layers

用两层克制的带状结构表达密封、涂层或冗余保护，呼应恶劣环境中的耐受能力。

- 可验证假设：设备制造商可联想到结构可靠性，而非消费电子的柔性波纹。
- 风险：层数过多会削弱轮廓；最多保留主层与保护层两级。

### H6 静默脉冲 / Quiet Pulse

在轮廓内部放置一个低振幅、单次脉冲动作，表达“持续感知但不过度喧哗”。

- 可验证假设：官网 Hero 有轻量动势，展板静止画面仍清晰。
- 风险：容易像无线/Wi‑Fi；不用同心多圈，不用霓虹光晕。

**适合**：官网叙事、系统集成场景、产品家族延展；三组中技术与温度最均衡。

## Territory 3 — 人本工程 / Human‑Engineered

**核心叙事**：可靠并非冰冷，而是工程师替客户把复杂性处理得恰到好处。

**设计语法**：外轮廓保持稳定，内部接合更友好、留白更从容；暖色只落在“感知发生的那一点”。暂定色感：深蓝 `#102C46`、石灰灰 `#707D82`、陶土橙 `#C7834E`、暖灰白 `#F2EEE6`。

### H7 柔性接点 / Rounded Junction

保留旧轮廓的力量感，只把内部尖锐交汇改为可制造、可触达的圆角接点。

- 可验证假设：CEO 感受到更有人情味，销售仍认为它属于工业设备而非生活方式品牌。
- 风险：圆角过多会显得消费化；外部骨架保持克制和硬朗。

### H8 工程字母构造 / Engineered Monogram

若真实品牌名与旧 Logo 本就包含首字母，则在原轮廓内用统一线宽与负空间重新组织字母；参考图只提供构成原则。

- 可验证假设：图形与中英文字标可形成清晰家族关系，同时不复制 NOMA 的任何字母方案。
- 风险：正式中英文名称尚未提供，此假设只能在名称确认后进入设计。

### H9 温暖感知点 / Warm Sensing Node

深蓝承担结构与可靠性，唯一的低饱和暖色节点标示“感知发生处”，把技术能力转成可理解的视觉焦点。

- 可验证假设：远距离展板上能快速聚焦，官网上也不需要光效来制造科技感。
- 风险：暖色面积过大会像食品或消费品牌；限定为单一小面积功能色。

**适合**：需要强调合作关系、工程服务与长期伙伴感的品牌表达；三组中温度最高。

这些是相对判断，不是替客户做出的排名。
