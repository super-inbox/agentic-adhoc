# v1 设计变更说明

## 已锁定并保留

- Creative Territory：C｜静音时序。
- 大留白、暖奶油 / 陶土红 / 炭黑 / 橄榄色彩关系。
- 01 / 02 / 03 的功能扫读节奏。
- 已批准文案：让香气慢下来；低噪运行；定时关闭；陶土触感。
- 产品身份、正视角、颜色与结构。
- 产品固定锚点：三张 1500 × 2000 模块中均为 `(675, 1045, 1460, 1625)`。

## 本轮唯一视觉变更

- 移除方向 C 中容易联想到参考海报的直线网格、矩形轨道与机械式几何关系。
- 改为原创“缓弧漂移”语言：开放、非同心、非正圆的三次贝塞尔缓弧，宽度沿路径渐变。
- 加入不规则陶土颗粒：随机尺寸、多边形边缘、疏密渐变，不使用重复纹样。
- 大胆构图由弧带的大尺度裁切、颗粒聚散与产品跨层关系承担。

## 模块分配

- 首屏：让香气慢下来；保留 01 / 02 / 03 功能序列。
- 卖点 01：低噪运行。
- 卖点 02：定时关闭 + 陶土触感；材质近景来自同一产品原图裁切。
