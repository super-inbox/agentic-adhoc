# 陶土红香薰机：参考拆解与方向假设 v0

状态：等待客户选择 Creative Territory。此版本只完成参考拆解、低成本假设与方向聚类；首屏和两张卖点模块尚未制作。

## 1. 参考拆解：只取原则，不取表面

### layout-ref｜01-layout_reference.png

可提炼：

- 大留白不是“空”，而是用约 45–55% 的低信息区域托住产品，让视线按“产品 → 主张 → 卖点 → 材质 → 参数”向下移动。
- 用清晰的横向分区控制信息密度：首屏最疏，卖点区适中，参数区最密。
- 居中产品与对齐网格形成稳定感；细分隔线负责结构，不靠装饰堆叠。
- 每个模块只回答一个问题，图片、标题、短句之间保持可预测的节奏。

明确舍弃：原参考的品牌、标题、香薰机造型、图标样式、材质照片、参数表外观与具体比例。

### palette-ref｜02-palette_reference.png

可提炼：

- 暖奶油色作为大面积底色，陶土红承担识别，炭黑保证文字可读，燕麦色与低饱和橄榄绿只做缓冲。
- 建议面积比：暖奶油 70%、陶土红 20%、炭黑 8%、橄榄绿 2%。
- 建议候选色：暖奶油 `#F4EFE4`、陶土红 `#B65343`、深陶 `#73382F`、炭黑 `#292825`、燕麦 `#D8C7AA`、橄榄 `#7F8B60`。
- 字体原则为“一个强标题层级 + 一个安静说明层级”，不沿用参考中的品牌字形或字标关系。

明确舍弃：MORI 品牌、叶形标志、品牌文字、纹样、样张排布与色块的原位置。

### geometry-ref｜03-composition_reference.png

可提炼：

- 通过大/小尺度反差、局部裁切、错位与跨栏，制造大胆构图；几何负责引导视线而非成为装饰主角。
- 保持少量形状、强对比和清晰边缘，每屏只设置一个视觉冲突点。
- 让产品或关键信息跨越两个模块，形成“从静到动”的阅读张力。

明确舍弃：原参考的圆弧网格、蓝橙配色、折纸物、环形标志、文字布局、活动信息与所有具体几何图案。

### product｜04-product_reference.png

- 产品身份锁定：保留陶土红机身、低矮圆柱比例、悬浮圆盘顶盖、黑色间隙、正面圆形按键与正视角。
- 仅允许原图的裁切、缩放和在新背景中的摆放；不重绘、不生成替代品、不改色、不改按钮、顶盖或轮廓。
- 本版本方向板使用逐字节复制的产品原图 `product-reference-exact.png`，未对产品像素做生成式修改。

## 2. 十个低成本原创假设

| 编号 | 假设 | 最小验证方式 | 预期信号 |
|---|---|---|---|
| H01 | 首屏保留至少 45% 负空间，会比满版场景图更贴近“让香气慢下来”。 | 用同一产品图做疏/密两个线框对照。 | 3 秒内先读到产品与主张，画面被描述为“安静”。 |
| H02 | 产品居中偏下、宽度约占画布 32%，能同时保留辨识度与呼吸感。 | 只调整裁切和比例，不增加道具。 | 顶盖、黑色间隙、按钮仍清晰可辨。 |
| H03 | 70/20/8/2 的奶油/陶土红/炭黑/橄榄比例能建立暖感而不发闷。 | 四色色块与真实产品并置检查。 | 产品不与背景融为一体，正文对比足够。 |
| H04 | “大标题 + 一句短文案 + 细线”的三级结构足以完成首屏，不需要额外图标。 | 仅使用已批准文案排版。 | 阅读顺序唯一，移动端不出现信息拥挤。 |
| H05 | 一块原创斜切色面穿过产品背景，可低成本获得大胆几何张力。 | 用纯色多边形而非插画。 | 视线落点仍在产品，形状不让人联想到参考 3 的圆弧网格。 |
| H06 | 将已批准的“慢下来”做大尺度局部裁切，可同时充当信息与构图。 | 只改变字号、裁切和对齐。 | 不依赖新摄影即可形成记忆点，文字仍可读。 |
| H07 | 用产品原图的局部裁切表达“陶土触感”，比生成新材质图更真实。 | 从同一原图取机身近景并配一句说明。 | 色泽与主产品完全一致，无虚构纹理。 |
| H08 | 用 01/02/03 序号替代通用功能图标，可降低制作成本并避免参考图标风格。 | 三个文字标签组成连续轨道。 | 用户能按顺序扫到低噪、定时、触感。 |
| H09 | “低噪”用低振幅平行线，“定时”用 1h/3h/6h 阶梯块表达，会比拟物图标更原创。 | 只画基础线段与矩形。 | 不看长文也能区分两项功能。 |
| H10 | 重复同一 12 栏网格、只改变跨栏宽度，能让首屏和两张卖点图统一且易适配移动端。 | 先做三张低保真模块并纵向重排。 | 三张图统一但不重复，移动端无需另造视觉语言。 |

## 3. Creative Territories

### A｜余温留白 / Residual Warmth

核心感受：最安静、最生活方式、最贴近“慢下来”。

- 聚类假设：H01、H02、H03、H04。
- 首屏机制：暖奶油大留白；产品居中偏下；标题与一句短文案悬在上方；一条深陶细线建立节奏。
- 卖点机制：卖点一用横向低密度线表达低噪；卖点二用留白中的三段时间标记表达定时，同时嵌入产品材质裁切。
- 风险：过度克制时可能显得信息弱；可通过字号而不是增加装饰解决。
- 成本：低。主要是排版、裁切和基础线条。

### B｜陶土切面 / Clay Facets

核心感受：最有新品发布感、视觉冲击最大，但仍保持暖与克制。

- 聚类假设：H05、H06、H07。
- 首屏机制：奶油与陶土红两块原创斜切色面；产品在交界处保持正视；“慢下来”超大裁切。
- 卖点机制：一张用长斜面压低“噪声”；另一张把真实产品局部裁切与时间块错位拼接。
- 风险：几何强度过高会抢产品；实施时限定一屏一个斜切焦点。
- 成本：低—中。无需新摄影，但需要更精细的响应式裁切。

### C｜静音时序 / Quiet Sequence

核心感受：最理性、功能最清晰，适合电商详情页快速扫读。

- 聚类假设：H08、H09、H10。
- 首屏机制：产品与 01/02/03 纵向序列并置；序号连接已批准的三条卖点；暖色块控制节奏。
- 卖点机制：低振幅线表示低噪，1h/3h/6h 阶梯表示定时；材质用同一产品图的真实裁切收尾。
- 风险：过度系统化可能偏“参数页”；通过暖奶油底色与大产品留白保留情绪。
- 成本：低。基础网格、线段与文字即可复用。

## 4. 选择提示

- 选 A：优先情绪、安静与高级留白。
- 选 B：优先新品冲击、社交传播与大胆构图。
- 选 C：优先功能扫读、信息效率与模块复用。

下一检查点只需要确认 A / B / C 其中一个主方向。收到选择后，再据此完成 1 张首屏和 2 张卖点模块；在选择前不会提前定稿。
