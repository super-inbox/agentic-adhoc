# 夜间香氛 KV 假设 · v0

本轮是内部选择用的低成本 4:5 母版，只验证视觉方向与构图，不是渠道成品。所有候选只使用已批准文案：

> Quiet hours, made tangible.  
> 让夜晚慢下来。

产品照均直接使用附件原图，只做等比缩放和位置变化；瓶型、标签、液体与瓶盖没有重绘或改动。由于未收到独立 Logo 文件，画面只预留 Logo 安全区，不放置猜造字标。

## Direction A · Soft Field / 柔光留白

以米白纸张、亚麻肌理和非常克制的陶土红作为“安静”的视觉证据。整体最轻、最留白，也最接近产品优先的编辑式静物。

- **A1 · Paper halo / 纸面光晕**：居中产品 + 横向米白文案卡；秩序最稳定，视觉噪音最低。
- **A2 · Quiet margin / 安静留边**：大面积米白边栏 + 偏置产品；更像独立杂志版面，留白最明确。
- **A3 · Clay header / 陶土标题带**：陶土红顶部色块 + 大比例产品；品牌色识别最直接，发布感更强。

## Direction B · Night Threshold / 夜间门廊

用米白墙面、陶土红立面和深色门廊形成从白天转入夜晚的“阈值”。仪式感来自光线与空间，而不是床、月亮或医疗语义。

- **B1 · Portal focus / 门廊聚焦**：深色文案卡 + 下方产品；光线叙事和产品识别较均衡。
- **B2 · Edge light / 边缘光**：产品左下、文案右上；偏置构图明显，空间张力更强。
- **B3 · Shadow split / 暗面切分**：黑色竖面 + 最大产品比例；夜间感最强，整体也最深沉。

## Direction C · Tactile Ribbon / 触感轨迹

把织物、纤维纸与陶土红弧线放到近距离观看，强调触感与手作痕迹。没有人物，也不借助“睡眠符号”。

- **C1 · Folded touch / 折叠触感**：米白标题区 + 居中产品；触感和清晰度之间最克制。
- **C2 · Close fabric / 近身织物**：上方材料特写、下方图文错位；编辑感最强、节奏最活。
- **C3 · Ribbon gesture / 缎带轨迹**：大产品 + 暗色织物背景；触感最戏剧化，陶土红存在感最高。

## 选择检查点

请内部选择一个编号（A1–C3）。在收到选择与独立 Logo 资产之前，不制作官网 hero、Instagram 竖版或邮件头图。
