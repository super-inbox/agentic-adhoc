# NOMA Logo A–D 评估（v0）

## 结论

**首选 C，建议进入下一轮；当前为设计建议，尚未替客户锁定。**

C 在“现代、友好、缩小识别、品类独特性”四项等权后得分最高。它不是四案里缩小最稳的，但以仍可接受的小尺寸表现，换来了明显更强的独特轮廓；综合取舍优于更稳但更通用的 B。

## 评估口径

- 每项 10 分，四项等权，总分 40 分。
- 证据来自所附候选板的可见造型，以及四个图形符号的 32 px 等尺寸缩小检视。
- 未提供 NOMA 的具体行业或竞品集合，因此“品类独特性”仅按本次明确目标操作化为：**是否避开房地产意象和通用 App 图标套路**。本评估不等同用户调研、竞品查重或商标检索。

## 逐项证据

### 1. C — 32/40

- **现代感 8/10：** 黑色与陶土色以连续线条交叠，造型不依赖外框，整体轻、流动、当代；少量交叉节点略增加复杂度。
- **友好度 8/10：** 大量圆角、软曲线和暖色让图形显得亲和，没有尖锐或压迫性的外轮廓。
- **小尺寸识别 7/10：** 32 px 时上下组合的大轮廓仍能成立；但瓶口的双色接点、中央交叠和下方两层内折线已开始变软，继续缩小时会比 B、D 更早粘连或丢细节。
- **品类独特性 9/10：** 上方瓶形与下方卷叠形态构成不对称的专属轮廓；既不像房屋/门廊，也没有套进常见圆形 App 徽章，四案中最能避开指定套路。

### 2. B — 30/40

- **现代感 8/10：** 圆形外框、简化线条和居中构图干净稳定；符号语言成熟但较常见。
- **友好度 9/10：** 点、弧线和碗形共同形成近似笑脸的表情，圆润且暖色点缀明确，是四案中最亲和的。
- **小尺寸识别 8/10：** 32 px 时外圆和碗形主结构保持清楚；上方弧线与小圆点略软化，但不会破坏整体识别。
- **品类独特性 5/10：** “圆形徽章 + 表情/容器”的构成很接近常见餐饮、健康或生活方式 App 图标；虽无房地产感，但通用 App 感明显。

### 3. D — 26/40

- **现代感 8/10：** 大色块拱形与黑色 N 字母组合简洁有力，几何秩序明确。
- **友好度 6/10：** 暖色圆拱带来柔和感，但黑色 N 的硬直线、尖角和较强视觉重量使整体更正式、冷峻。
- **小尺寸识别 8/10：** 32 px 时粗壮外轮廓保持最好之一；窄白槽和内部黑色竖线会变紧，但主体仍清楚。
- **品类独特性 4/10：** 拱门/入口/建筑立面的联想较强，同时又是常见字母组合标；容易靠近地产、酒店或通用品牌 App 的视觉惯例。

### 4. A — 22/40

- **现代感 7/10：** 几何线条、字母与双色圆环具有当代感；但屋顶、N 与 O 多层交叠，视觉关系比其余方案更拥挤。
- **友好度 6/10：** 暖色圆形有所缓和，但屋顶尖角、粗黑斜线和强烈交叉让气质偏硬。
- **小尺寸识别 6/10：** 32 px 时大致轮廓仍在，然而屋顶、N 和 O 在右下交汇处挤成重节点，负形变窄；缩小后先读成“房子”，字母关系反而退后。
- **品类独特性 3/10：** 屋顶、门框式竖线和房屋轮廓是最直接的房地产/家居提示，与“避免像房地产”正面冲突。

## 首选 C：下一轮唯一改动项

**只做图形符号的小尺寸光学校正；不重画概念，不改整体轮廓、黑/陶土配色、NOMA 字标或上下构图。**

具体执行限定在同一个目标内：让 24–32 px 时三个拥挤点仍然分开。

1. 减少或拉开下方卷叠形态的内层回线，避免两条陶土色横线合并。
2. 给中央黑/陶土交叠处增加一点负空间，避免形成单个厚结。
3. 清理瓶口双色接点，让连接在小尺寸下不形成黑橙色块。

下一轮验收只看一件事：在 24 px 与 32 px、浅色和深色背景上，上述三处不粘连，同时 C 的现有大轮廓和气质保持不变。
