# Curify tool provenance

`curify-costume-tryon-contact-sheet.png` is a six-frame contact sheet extracted from one successful
production run of Curify's anonymous `POST /costume-tryon/generate` tool. The input was the synthetic
adult fixture from reference-pack-v0.1, so the output contains no user personal data.

The contact sheet is generation evidence, not a query input or a substitute for the three try-on
input fixtures. It remains outside `manifest.jsonl` by design.
